What this proves

The private verifier checks the intended run, submitted task values, unique server commit and signed receipt. Interface text and completion claims cannot pass that check on their own.

Suggestions are separate from verified outcomes. NVIDIA diagnosis runs only when a bounded, owner-authorized cloud campaign is active. A model explanation cannot create a receipt or execute recovery without human approval.

Evidence contains hashes and verdicts, not contact values, credentials or model reasoning. Sessions expire after 30 minutes. Local sessions disappear on restart. HMAC verification occurs privately; exported JSON is a review record, not a public-key certificate.
