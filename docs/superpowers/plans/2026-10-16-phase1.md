# Phase 1 Implementation Plan

**Goal:** Prove server-verified recovery on synthetic form tasks and prepare an honest Nemotron comparison.
**Architecture:** Local HTTP form state machine, independent receipt verifier, Playwright agents with a bounded policy interface, benchmark JSON artifacts.
**Tech stack:** Node 24, node:test, Playwright Chromium, native fetch/crypto/http.
**Spec:** docs/superpowers/specs/2026-10-16-phase1-design.md

## Global constraints
Cloud-only, one repository, synthetic data, loopback app, no paid model calls without approval, no public deployment, no secrets in logs.

## Review focus
- Cross-session receipts, incorrect payloads and repeated submissions must fail verification.
- UI success text without a durable server record must fail verification.
- Model actions must never reach evaluator endpoints or external origins.
- Provider errors, absent usage, malformed actions and exhausted budgets must fail closed.
- Browser/HTTP resources must close on failure; benchmark output must distinguish scripted from live inference.
