# Product decision — October19 gate, evidence reviewed October17

**Proceed with ReceiptLab as a bounded verification and diagnosis workbench; pivot away from claims of superior autonomous form filling. Public-release readiness remains no-go.** The independent receipt boundary is working, and real Nemotron diagnosis now solves some natural-language failures that independently authored deterministic rules miss. Model reliability, comparator quality and judge deployment are not yet sufficient for broad efficacy or release claims.

## Product and release gates

Keep the useful contract: source-grounded explanations, explicit uncertainty, optional safe recovery recommendation, independent task/run verification and export provenance. Human approval must precede executable synthetic recovery; model output has no completion authority. Default inference remains inactive. Do not implement automatic external recovery, generic web browsing or a search feature to satisfy NVIDIA eligibility cosmetically.

Bounded runtime-protocol experimentF is documented separately afterE: intermediate accepted draft steps are not commits, so a later submission error plus incomplete verifier result is compatible evidence. This changes trusted application context uniformly, not standalone held-out labels or a comparator. F now establishes known-case integration, not independent model superiority. Its high-confidence incorrect negative recommendation is a release risk; a private guard blocked it. Full outcomes are in diagnosis-sprint.md and exact artifacts.

Before final submission: complete credible unseen safety/contradiction coverage, obtain external expert/user review and compare a practical stronger alternative, address reasoning/truncation latency using only provider-supported controls, validate secure judge-accessible deployment through December15, and obtain license/eligibility/media approvals. Preserve the50USD judging reserve. Do not spend to fill charts or repeatedly retry consumed failures.

If reliable useful NVIDIA diagnosis cannot survive these gates by the remaining schedule, do not submit it as a proven autonomous agent. Preserve ReceiptLab's verifier/QA work and explicitly recommend no-go for the hackathon's NVIDIA-powered release. Four official judging categories are equally weighted; local test count alone does not answer implementation impact, design or idea quality.
