## State and ingress safety

The current hosted snapshot adapter stores the HMAC verifier key, private synthetic application records, sessions and run state in one PostgreSQL JSONB row. `revision` compare-and-swap rejects stale concurrent writers; on any conflict or database failure, that process stops serving confirmed success. Each HTTP response waits for its PostgreSQL write. Startup converts interrupted diagnosis/recovery to a review-required state while retaining consumed approvals. A process-local request queue makes the one-service free deployment sequential. SQLite remains the local reference. Public and judge entry points share the `receiptlab` application-state namespace so switching entry points preserves existing sessions, receipt keys and approvals. The judge budget is isolated under `receiptlab-judge`.

Render ingress trusts the configured canonical Host and requires exactly `X-Forwarded-Proto: https` when `RECEIPTLAB_RENDER_PROXY=true`. It never derives origin from `X-Forwarded-Host`, `Forwarded`, or client IP headers. POST `Origin` must match the configured canonical origin. Public cookies stay Secure, HttpOnly and SameSite Strict. Issue #5 records successful HTTPS health and the external deterministic acceptance. The current Work runtime's 15-second GET to `/health` timed out; it does not establish current outage or uptime.

The PostgreSQL judge-credit accounting adapter stores per-call reservations, token settlements, access attempts, consumed runs and failure halts in one Neon transactionally locked budget row. It checks the unchanged canonical account history and a matching reserved campaign envelope before admission. Model POST admission is limited by total, per-day, per-session, scenario, token and estimated-cost limits; each reservation commits before the POST. Unsettled requests remain fully charged and halt the campaign across restart. Strict provider usage is settled, the semantic gate must accept its output, and only then is the call finalized. The judge controller never retries. This is an estimated credit envelope: Nebius prices are checked before each call, but the provider does not enforce the estimate as a hard invoice ceiling.

PostgreSQL tests use a local PostgreSQL 17 service with simulated provider responses. These tests prove request orchestration and safety behavior, not live NVIDIA execution or deployment. The existing real v3 result stays negative and partial: 1/4 label matches and 2/4 safe actions against the 3/4 deterministic comparator on that small paired sample.
