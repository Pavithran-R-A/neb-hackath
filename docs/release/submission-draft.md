## Devpost description draft

Browser agents can say “done” when a page only looks successful. ReceiptLab compares those claims with private application state and a run-bound signed receipt, then helps investigate failure. Its synthetic multi-step workflows reproduce confusing controls, validation failures, consent expiry, misleading success and contradictions.

NVIDIA Nemotron through Nebius Token Factory examines source-tagged traces, cites evidence and recommends a constrained recovery. Suggestions have no completion authority. Recovery requires explicit approval and an independent current-state permission guard; a separate verifier checks the intended task/run, unique server commit and receipt after execution.

Real cloud Chromium integration recorded a transient-failure diagnosis, approved synthetic retry and verified completion. A second real case exposed incorrect high-confidence retry advice after misleading success; the private guard blocked execution and verifier rejected completion. This failure is retained, not edited into a model safety success. All user-facing model metrics are actual provider usage/latency/estimates, clearly separate from simulated integration tests.

The October18 synthetic v2 evaluation completed16/16diagnoses with NVIDIA Nemotron Lightning: raw diagnosis12/16, recovery12/16, paired agreement10/16. An independently authored telemetry comparator scored12/16,10/16and8/16 respectively. Two model diagnoses were incorrect at high confidence. A subsequent review gate replayed the same consumed outputs with zero inference:9accepted,4abstained,3review-required; neither observed high-confidence error remained accepted, while displayed pair agreement fell to6/16. This is post-hoc safety adaptation, not fresh held-out validation. A separate remaining-v1 run completed9/9traces with raw pair agreement5/9; earlier failures remain preserved. On October19, a fresh v3 live campaign stopped safely after four usable diagnoses when a fifth returned HTTP200/exact model but `finish_reason=length` at8192 reasoning/output tokens; eleven traces were unattempted. On the same four usable cases, Nemotron matched1/4 diagnosis/action labels versus3/4 for the deterministic comparator, and the gate accepted one trace the independent expected disposition marked review-required. This is a partial negative result, not a full-suite estimate; the failure and usage remain preserved. A targeted post-hoc gate replay marks unresolved writes review-required, but consumed v3 data cannot confirm that change. AI-authored, labels-visible independent review is not external human expert validation. No general diagnostic or autonomous-completion superiority is claimed. Earlier form comparisons found no completion-rate advantage over competent DOM automation.

Intended users are agent developers investigating false completion and failed workflows. External adoption, impact and arbitrary-website reliability remain unvalidated. No public demo is deployed; repository license, final eligibility and judge test-build access remain pending. Candidate track: Best Apps and Agents, subject to official eligibility review. **Do not submit this working draft as release-ready software.**

Atomic SQLite state, an exclusive instance lease and retained cumulative budgets support the prepared architecture. This is local integration evidence, not public deployment, public certificate or free-hosting entitlement.
